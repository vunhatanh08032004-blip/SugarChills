# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

SugarChills (`QL_MatHangAnUong`) — a Vietnamese university course project: a drinks/desserts shop. ASP.NET MVC 5.2 on .NET Framework 4.7.2, Razor, Entity Framework 6 **Database First** (`.edmx`), SQL Server. Code identifiers, comments and UI strings are in Vietnamese. `README.md` is the up-to-date source for features and business rules; `HUONG_DAN_SUGARCHILLS.md` is **stale** (describes an old in-memory-data phase) — don't trust it.

## Commands

Windows + Visual Studio 2022 only (no `dotnet` CLI, no test project, no linter).

- Database: run `QL_MatHangAnUong_ToanBo.sql` in SSMS. It drops and recreates database `QL_MatHangAnUong` with all tables and seed data (re-runnable, destructive). `TaoBang_DanhGia.sql` / `TaoBang_LienLacs.sql` are partial scripts already included in it.
- Restore + build: `nuget restore QL_MatHangAnUong.sln`, then `"C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" QL_MatHangAnUong.sln /p:Configuration=Debug` (or Rebuild in VS).
- Run: F5 in VS (IIS Express). Connection string `QL_MatHangAnUongEntities` in `QL_MatHangAnUong/Web.config` defaults to `data source=.\SQLEXPRESS`; change it for other instances.
- Seed logins: Seller `seller@sugarchills.vn`, customers `khach@gmail.com` / `khoa.tran@gmail.com`, all password `123456`.
- Secrets: copy `Secrets.config.example` → `Secrets.config` (git-ignored, merged via `<appSettings file="Secrets.config">`) for Google/Facebook OAuth and Gmail SMTP (`SmtpUser`/`SmtpPass` app password for the forgot-password OTP). Everything degrades to a "not configured" message when empty.

## Architecture

Flow: Browser → Controller (inherits `BaseController`) → EF6 `QL_MatHangAnUongEntities` → SQL Server → Razor view. Single default route `{controller}/{action}/{id}`; no Areas — the seller back office is just `QuanLy*` controllers with their own `_LayoutSeller.cshtml`.

- **`BaseController`** owns the per-request `db` context (disposed in `Dispose`), and in `OnActionExecuting` sets the culture from the `scNgonNgu` cookie (`vi`/`en`), and fills `ViewBag` with current user, category menu, and cart count that the layouts depend on. It also provides `ThongBao()` (one-shot TempData flash message) and `PhanTrang()` (pagination in SQL or in memory; the IQueryable overload requires an `OrderBy`, and feeds `Views/Shared/_PhanTrang.cshtml` via ViewBag).
- **Auth is Session-based, not ASP.NET Identity.** `Helpers/PhienLamViec` is the single place that reads/writes `Session` (logged-in `NguoiDung`, cart). Authorization uses `[KiemTraDangNhap]` and `[KiemTraNguoiBan]` in `Filters/PhanQuyenAttribute.cs` (Seller role = `NguoiDung.RoleSeller`); the login filter returns JSON `{canDangNhap:true}` for AJAX requests instead of redirecting. Google/Facebook login is a hand-rolled OAuth code flow in `Helpers/DangNhapMangXaHoi` + `TaiKhoanController.*Callback`; `Startup.cs` and `App_Start/Startup.Auth.cs` (OWIN) are **not in the `.csproj`** and have no OWIN references in `packages.config`, so they are dead files that don't compile into the app. Passwords are stored plain text (known, documented limitation).
- **Cart** (`Models/GioHang.cs`) lives in `Session["GioHang"]`. A line's identity is `GioHangItem.Khoa` = product + size + sugar + ice + sorted toppings. Size/topping surcharges and the topping price list are centralized in the static `TuyChonSanPham`; controllers re-validate options against it server-side. Checkout (`GioHangController.TaoDonHangVaTruKho`) runs a Serializable transaction that creates the order and decrements stock; cancelling an order restores stock. Order line items snapshot `TenSP`/`DonGia`/`TuyChon` at purchase time.
- **Models**: entity classes are **generated by T4 from `Models/QL_MatHangAnuong.edmx`** — don't hand-edit them (note the file on disk is `QL_MatHangAnuong.*` while git tracks `QL_MatHangAnUong.*`; this casing mismatch on Windows shows up as spurious modifications in `git status`). Add behavior in the `*Partial.cs` files (e.g. `DonHangPartial.CssTrangThai`, `KhuyenMaiPartial.TinhTienGiam`). After changing the schema: edit SQL, then *Update Model from Database* in the `.edmx` designer. `ViewModels/` holds screen-specific models. Controllers query EF directly through `db`; there is no separate data-access layer.
- **Localization**: `App_GlobalResources/Strings.resx` (vi) and `Strings.en.resx`. Views use `@Resources.Strings.Key`; **Controllers/Models/Helpers must use `Ngu.S("Key")`** because global resources are compiled at runtime, not by MSBuild, so `Resources.Strings` doesn't exist at build time in `.cs` files (CS0103).
- **Business rules worth knowing** (details in README §2): order states Chờ xác nhận → Đã xác nhận → Đang giao → Hoàn thành, or Đã hủy (terminal states are immutable); Hoàn thành auto-marks paid (`SoTienConLai = 0`) and only Hoàn thành orders count toward revenue; reviews (`DanhGia`) require a completed order containing the product, once per product; forgot-password OTP is Session-only (6 digits, 5 min expiry, attempt/resend limits) and mails via `Helpers/GuiMail`.
- Every POST form uses `@Html.AntiForgeryToken()` + `[ValidateAntiForgeryToken]`, and redirects validate `Url.IsLocalUrl(returnUrl)`.
